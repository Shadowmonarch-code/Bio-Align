   324→   - Problem: `getNavigationTarget()` function didn't handle `/plant-breeding/*` URLs
   325→   - URLs like `/plant-breeding/genetic-params` fell through to default case
   326→   - Default case returned view name as path which didn't match any view in page.tsx
   327→   - **Solution**: Added proper URL pattern matching:
   328→     ```typescript
   329→     // Plant Breeding section - all map to plant-breeding view
   330→     if (href.startsWith("/plant-breeding")) {
   331→       return { view: "plant-breeding" }
   332→     }
   333→     
   334→     // Bioinformatics section - map to analysis view with toolId
   335→     if (href.startsWith("/bioinformatics")) {
   336→       const toolId = href.replace("/bioinformatics/", "")
   337→       return { view: "analysis", toolId }
   338→     }
   339→     
   340→     // Thesis Studio section - map to thesis view
   341→     if (href.startsWith("/thesis")) {
   342→       return { view: "thesis" }
   343→     }
   344→     
   345→     // Visualization section
   346→     if (href.startsWith("/visualization")) {
   347→       const toolId = href.replace("/visualization/", "")
   348→       return { view: "analysis", toolId: `viz-${toolId}` }
   349→     }
   350→     ```
